# Laravel MVC — Учебные группы и студенты

Учебный проект по курсу «1.2. МВС. Базы данных» (Нетология).

## Описание

Приложение для ведения учебных групп и студентов на Laravel.

## Технологии

- PHP 8
- Laravel 11
- SQLite

## Функциональность

- Просмотр списка групп
- Создание новой группы
- Просмотр группы со списком студентов
- Создание студента в группе
- Просмотр информации о студенте

## Вопросы

### 1. Для чего нужны миграции?

Миграции — это версионный контроль для базы данных. Они позволяют создавать и изменять структуру таблиц с помощью PHP-кода вместо SQL. Это решает проблему синхронизации структуры БД между разными разработчиками и окружениями (локальное, тестовое, продакшн).

### 2. Для чего нужен фасад ORM?

Eloquent ORM позволяет работать с таблицами базы данных как с PHP-объектами, не писать SQL-запросы вручную. Каждая модель соответствует таблице, а отношения между таблицами описываются методами (hasMany, belongsTo). Это упрощает код и делает его читаемым.
