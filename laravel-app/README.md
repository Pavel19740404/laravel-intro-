# Задание 3. Установка Laravel

## Ответы на вопросы

### 1. Composer-пакеты Laravel после установки
laravel/framework, laravel/tinker, laravel/pail, laravel/pao, laravel/prompts, laravel/agent-detector и другие (70+ пакетов включая symfony, monolog, psr и т.д.)

### 2. Файлы в директории config/
- app.php — основные настройки приложения
- auth.php — настройки аутентификации
- cache.php — настройки кэширования
- database.php — настройки базы данных
- filesystems.php — настройки файловой системы
- logging.php — настройки логирования
- mail.php — настройки почты
- queue.php — настройки очередей
- services.php — настройки сторонних сервисов
- session.php — настройки сессий

### 3. Директория с бизнес-логикой
Основные файлы (классы) с бизнес-логикой хранятся в директории `app/`
